## 📋 Project Overview
This project applies Unsupervised Machine Learning techniques to a dataset of physicochemical wine properties. The objective was to reduce dimensionality while preserving information and to uncover natural groupings within the wine samples without relying on pre-existing labels.

**Key Techniques:** Principal Component Analysis (PCA), Spectral Clustering.
